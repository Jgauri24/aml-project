# Model comparison demo findings

Run: `python -m examples.model_suite_demo`  
Data: two synthetic SKU-store series, one forecast origin (d_140), 28-day horizon.  
Paired observations: 56 per model pair; unmatched rows: zero. Bootstrap: 500
SKU-store cluster resamples, percentile 95% intervals, seed 42.

## Descriptive rankings

- MAE: Seasonal Naive 0.232 (rank 1), LightGBM 0.294 (2), Kalman 0.577 (3),
  DeepAR 1.330 (4).
- RMSE: LightGBM 0.467 (rank 1), Seasonal Naive 0.482 (2), Kalman 0.653 (3),
  DeepAR 1.551 (4).
- WAPE: Seasonal Naive 0.119 (rank 1), LightGBM 0.151 (2), Kalman 0.296 (3),
  DeepAR 0.683 (4).
- Among probabilistic models, Kalman ranked ahead of DeepAR on P10/P50/P90
  pinball loss and WIS. Seasonal Naive and LightGBM do not emit quantiles and
  are correctly unranked for probabilistic metrics.
- On this run's measured compute times, Seasonal Naive was fastest for fit and
  prediction; this is a single synthetic run and not a stable runtime benchmark.

## Paired bootstrap examples

Differences are model A minus model B, so negative values favor A. The MAE
interval for Seasonal Naive minus LightGBM was -0.062 (-0.184, 0.061), which
contains zero. The other MAE intervals excluded zero in this two-series sample:
Kalman minus LightGBM 0.283 (0.131, 0.435); Kalman minus DeepAR -0.753
(-1.148, -0.358); LightGBM minus DeepAR -1.036 (-1.583, -0.489); Seasonal
Naive minus Kalman -0.345 (-0.620, -0.070); Seasonal Naive minus DeepAR -1.098
(-1.768, -0.429).

For Kalman minus DeepAR, probabilistic bootstrap differences favored Kalman:
P10 -0.104 (-0.143, -0.066), P50 -0.377 (-0.574, -0.179), P90 -0.122
(-0.164, -0.080), and WIS -0.402 (-0.587, -0.217).

## Inference limits

Every DM result is `insufficient_origins`: this run has only one forecast
origin, while the implementation requires at least eight. No DM p-value or
statistical significance conclusion is produced. The bootstrap resampled only
two series, so its intervals are extremely coarse and conditional on these
synthetic series; intervals that exclude zero are descriptive and must not be
presented as evidence of retail-population significance. The repository's
historical retail comparison CSVs contain aggregate metrics but not common
row-level forecasts, so a paired retail significance analysis still requires
rerunning the model suite/backtester and retaining aligned predictions.

All result tables in this folder were generated by the demo: `paired_comparisons.csv`,
`dm_tests.csv`, `bootstrap.csv`, and five distinct ranking CSVs.
